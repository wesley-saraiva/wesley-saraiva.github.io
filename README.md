# Wesley Saraiva — International Portfolio

Responsive bilingual portfolio for Wesley Saraiva, focused on Flutter and Java/Spring Boot development.

## Live site

<https://wesley-saraiva.github.io>

## Highlights

- Portuguese and English language switcher
- Responsive layouts for mobile, tablet, notebook, and desktop
- Flutter, Dart, Java, Spring Boot, MySQL, and Git
- Residencial Andaralua (RAL) full-stack case study
- LinkedIn and GitHub contact links

The static site is deployed automatically through GitHub Actions whenever the `main` branch is updated.
